# 全流程验收清单

本清单面向服务器更新后的人工验收。当前只有隔离的 TEST 租赁闭环；真实 Google、PVS 和 WsCharge 仍需单独配置和联调。保留原客户界面和 Rent / Stations / Rentals / Account 底部导航，不引入钱包充值。

## 客户端

1. 未登录点击扫码或帮助，登录后继续原来的任务；登录取消或过期显示可恢复入口。
2. 同一浏览器退出再登录可恢复自己的 TEST 订单；退出后不显示旧订单和工单。切换账户时，延迟响应不能覆盖新账户。
3. 点击扫码直接请求相机；拒绝权限、不支持扫码或相机不可用时，可手输 DEMO-001 或使用 Mock scan。离开页面或关闭弹层后停止相机。
4. 无效机柜编号给出明确提示，不创建订单。已有进行中订单时回到该订单，不新建第二笔。
5. 报价显示押金、费率和计费规则。五分钟报价过期后重新扫码报价；已创建订单沿用其价格快照，不偷偷改价。
6. 支付失败不计费、不收押金，允许重试或取消；支付成功进入等待取出，费用仍为零。
7. 模拟取出成功后开始服务器计时；未取出取消或模拟取出失败，显示全额模拟退款。真实设备命令 ACK 不能当成取出成功。
8. 使用中刷新、切回页面或重新登录，恢复现有订单。不同页面的金额来自同一服务器计费规则。
9. 归还确认后停止计时，显示租金、已付押金、押金抵扣、退款及订单参考号。重复操作不重复扣费或退款。
10. 费用超过押金时仅列明待处理差额，不擅自追加扣款；旧零押金订单保留原有规则，不能显示虚构的退款。
11. 提交客服问题保留失败时的草稿。网络结果不确定时，重试同一消息不会生成重复工单。仅当前账户可查看自己的工单和后台回复。
12. 返回、前进、取消、重复点击及网络延迟后，页面不得突然跳回旧流程；已确认成功的操作不能因后续刷新失败而提示操作失败。

## 管理后台

1. 管理员入口独立；客户账户无法进入。owner / operator / viewer 的操作能力与服务端权限一致。
2. 首次加载失败不是“零订单”；刷新失败保留旧数据显示并明确告知可能过期。
3. 保存期间防止重复提交。保存成功与随后刷新失败分别提示，避免用户再次提交。
4. 站点坐标同时填写或同时留空；机柜编号不可因长度限制被静默截断。
5. 站点、价格或工单已被其他管理员修改时，旧表单保存遭拒绝并要求重新加载，而非静默覆盖。
6. 有未保存修改时，站内切页、刷新、退出先给出保留或放弃选择。
7. TEST 订单、押金、租金及退款单独标记，不能计入真实营业额。进行中费用为估算值，结算完成后才是最终值。
8. 管理后台的正式价格配置不改变 DEMO-001 固定示例价格。不得将演示价格理解为已确认的商业费率。
9. 工单完成必须有客户可见的回复；只读管理员不得保存回复或状态。

## 验证边界

- 自动化测试覆盖 API、客户页面控制逻辑、管理页面控制逻辑和历史数据兼容；构建检查单独运行。
- 本地实际 HTTP 服务冒烟测试覆盖登录、扫码报价、押金失败/重试、等待取出、取出、归还退款、历史与后台权限隔离。
- 自动化控制逻辑测试不等于 Android/iOS 实机视觉、相机权限或真实扫码测试。更新服务器后应按上述步骤做手机验收。
- 不含真实支付、真实退款、真实 Google OAuth 和厂商机柜端到端验证，也不代表运行中的服务器已自动更新。
- 更新前按 PRODUCTION.md 备份数据库；本轮流程修复不新增数据库 schema，沿用 v4。
